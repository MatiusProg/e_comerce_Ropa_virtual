# 3.3 Diagramas de secuencia de la 3ra presentación: los fragmentos combinados

*Lo genera `scripts/p3_fragmentos_md.py` a partir de los guiones `scripts/ea-secuencia-p3-<a..e>.datos.ps1`; no se edita a mano.*

Cada fragmento sale de una estructura de control del código (el comentario de cada guion dice el archivo y la línea): **alt** = if/else o `raise` excluyentes, **opt** = if sin else, **loop** = for, **break** = `raise` temprano, **critical** = commit con rollback. Para cada operando se indica su guarda y entre qué mensajes va. El generador (`scripts/ea-secuencia-p3.ps1`) ya los dibuja; esta lista sirve para revisarlos o rehacerlos a mano en EA si se mueve algo.

## 3.3 CU-21 Gestionar el inventario de la sucursal
1. **loop**
   - [por cada línea del ingreso]: desde «2.4: obtenerOCrear(variante, sucursal)» hasta «2.5: agregar("INGRESO", cantidad, proveedor, referencia)» (2 mensajes)
2. **loop**
   - [por cada operación del lote]: desde «4.14: operacionPorUuid(uuid)» hasta «4.17: guardar(operacion, "CONFIRMADA")» (4 mensajes)
   3. **critical** — dentro del fragmento 2
      - (sin guarda): desde «4.15: fisicoAlMomento(variante, sucursal, creadaEn)» hasta «4.16: ajustarPorDiferencia(variante, sucursal, diferencia, motivo)» (2 mensajes)
4. **alt**
   - [en línea, lo contado es igual a lo que hay]: solo «5: conteoSinDiferencia() -> 409»
   - [en línea, lo contado es menos que lo reservado]: solo «5.1: conteoMenorQueLoReservado(reservada) -> 409»
   - [sin conexión, el conteo resta más de lo disponible]: desde «5.2: stockInsuficiente(disponible)» hasta «5.4: rechazada(uuid, motivo)» (3 mensajes)
